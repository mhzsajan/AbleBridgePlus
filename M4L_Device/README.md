# M4L Device for AbleBridgePlus

This directory contains the Max for Live device for AbleBridgePlus.

## Overview

The M4L Device provides access to hidden parameters and advanced features via the Live Object Model (LOM).

## Features

- Hidden parameter access
- Rack chain internals
- Audio analysis
- Property observation
- AB comparison

## Installation

1. Open Ableton Live
2. Go to Max for Live → Max Audio Effect
3. Import the device from this directory

## Usage

1. Load the M4L Device onto any track
2. The device will automatically connect to the MCP Server
3. Use the M4L-specific tools in the MCP Server

## Requirements

- Ableton Live 10, 11, or 12
- Max for Live (included in Suite or available as add-on)
