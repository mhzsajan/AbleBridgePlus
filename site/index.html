The idea

What is an MCP bridge?

You've seen tools like this described as “an MCP bridge”. Here's what that means, without the jargon.

1

The problem

AI assistants are great at talking and poor at doing. Ask one to tighten a compressor and it will happily explain how — but it can't reach into your computer and turn the knob.

2

The fix — MCP

Model Context Protocol is an open standard that lets an assistant connect to other software. Think of it as a universal plug: a tool says what it can do, and any assistant that speaks the standard can use it.

3

The bridge

Ableton doesn't speak MCP, and MCP doesn't speak Ableton. This is the translator in between — software that does the work in Live through Ableton's own official controls.

What you can ask

Seven things it does well

You never memorise a command. You say what you want the way you'd say it to a producer sitting next to you.

Make me a track

“produce a demo: energetic 128 BPM house in G minor”

Sets the tempo, builds Intro / Verse / Chorus / Drop scenes, and writes chords, bassline, drums and a lead hook — all in key.

Turn what I played into a clip

“turn what I hummed into a full clip”

Captures your playing, quantizes the timing, and adds matching chord pads underneath in the right key.

What's this sample?

“what key and BPM is that sample on track 3?”

Real audio analysis, not a guess — key, tempo and a confidence value. It can then turn the audio into editable MIDI.

Do my tracks clash?

“do any of my tracks clash with each other?”

Finds tracks fighting over the same frequencies, then suggests fixes: pan one away, EQ the collision, or duck a few dB.

Keep my computer fast

“Ableton is getting heavy, freeze what I don't need”

Finds the heaviest tracks that are playing right now, flattens them to audio, and checks the result.

Remember how I work

“remember I always work at 124 BPM in F# minor”

Stores it permanently, so tomorrow's session starts already knowing. Ask “what did you change today?” any time.

Run my live show

“fire scene 5, then go to the next scene every 16 bars”

Hands-free scene sequencing with per-section tempo, plus one-command emergency stop, panic mute and session backups. Plus video, DMX lighting, setlists and timers.

What it can't do: render or export audio (Ableton doesn't allow that), hear your speakers in real time, or work with any DAW other than Live. Key and BPM detection are estimates — always confirm by ear.

The important part

Is it safe to let an AI touch my music?

Reasonable question. Four things make it safer than it sounds.

It only acts when you tell it to

No autonomous behaviour. It waits for you.

It saves your work first

Before changing anything it snapshots your set — tracks, mixer, arrangement. Change your mind? One word puts it back.

It keeps a diary

Every change is written down: what tool, what arguments, what happened, when. Ask “what did you change today?”

It can only do what you could do

It talks to Live through the same official interface a person would use. No back door into your system.

And your music never leaves your computer.

The AI assistant, this bridge and Ableton all run locally. Your project is never uploaded anywhere, there's no telemetry and no account to create. Once installed it works offline. It's also MIT licensed — you can read every line of it.

Setup

Get started in about ten minutes

  • Ableton Live11 or 12
  • Python3.10 or newer
  • An AI assistantClaude, OpenCode, Cursor…
  • Accounts to createNone

  1. Install

    git clone https://github.com/mhzsajan/AbleBridgePlus.git
cd AbleBridgePlus
uv sync

  2. Put the script inside Live

    Download the release and run the installer, or copy the AbleBridgePlus/ folder by hand: 

    # Windows
%USERPROFILE%\Documents\Ableton\User Library\Remote Scripts\

# macOS
~/Music/Ableton/User Library/Remote Scripts/

    Then in Live: Preferences → Link, Tempo & MIDI → Control Surface → AbleBridgePlus. Restart Live if it was already open.

  3. Connect your AI client

    Add to ~/.config/opencode/opencode.jsonc:

    "mcp": {
  "ablebridge": {
    "type": "local",
    "command": [
      "C:/path/AbleBridgePlus/.venv/Scripts/AbleBridgePlus.exe",
      "--transport", "stdio"
    ]
  }
}

    Add to claude_desktop_config.json:

    {
  "mcpServers": {
    "ablebridge": {
      "command": "python",
      "args": [
        "C:/path/AbleBridgePlus/mcp_stdio_launcher.py",
        "--transport", "stdio"
      ]
    }
  }
}

  4. Check it works

    Ask your AI:

    run the doctor

    doctor reports connection state, script-version drift, port conflicts and cache staleness in plain language, each with a suggested fix.
